# CARD — Мой кошелёк

Мобильная PWA-версия кошелька скидочных и бонусных карт.

## Возможности
- локальное хранение карт в браузере;
- сканирование QR и распространённых штрихкодов камерой;
- крупное отображение QR/штрихкода для предъявления;
- ручное добавление и редактирование;
- поиск;
- JSON-резервная копия и восстановление;
- PWA с service worker.

Камера в Safari/iPhone требует HTTPS и разрешение доступа к камере.
